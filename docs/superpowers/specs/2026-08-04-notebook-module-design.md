# Точка Сборки: «Пакет тетрадки» (M1) + модуль «Учиться с ИИ-тетрадкой» (M2)

**Дата:** 2026-08-04 · **Статус:** draft → owner review
**Происхождение:** Evernote «Tochka sborki + Nautilus research» (Gemini Notebook, ex-NotebookLM,
как ридер YouTube) + intake #102 fast.ai inverted curriculum (NAUTILUS
`docs/superpowers/research/2026-08-04-fastai-pattern-intake.md`). Owner-решение исходного
brainstorm: «новый модуль курса + продуктовая фича», движок = **handoff/prompt-emitter**.

## 1. Несущая идея

Ученик уже утопает в видео и PDF. Source-grounded тетрадка (Gemini Notebook и класс
инструментов вокруг) превращает кучу источников в конспект, где каждое утверждение
кликабельно в точку источника. Курс НЕ думает за ученика и НЕ ходит в LLM сам — он
собирает **готовый пакет**: что положить в тетрадку, какие промпты дать и как проверить,
где тетрадка врёт. Тот же суверенный паттерн, что learn-with-AI / prompt-emitter семья:
ноль ключей, ноль backend, работает и без подписки Google (промпты годятся любому чату).

**Инверсия fast.ai (#102, принятое требование):** юнит 1 модуля = РАБОТАЮЩАЯ тетрадка за
15 минут. Теория («как устроено») и скепсис («где врёт») — ПОСЛЕ того, как у ученика на
руках работающий артефакт.

## 2. M1 — «Пакет тетрадки» (`/notebook`)

Паттерн-эталон: `/try` (`lib/course/try-chains.ts` → `components/try-chains.tsx` → open
page, без почты). Всё — engine+data по канону `lib/course/*` (`Bi{ru;en}` + resolver).

### Файлы
- `lib/course/notebook-pack.ts` — данные+движок:
  - `NotebookPack` (keyed): `id, icon, title, situation, sources (Bi-инструкция «что
    положить»), steps` — минимум три пака:
    1. **`youtube-playlist`** — плейлист/подборка роликов → тетрадка (сценарий исходной
       заметки: «NotebookLM смотрит YouTube за меня»);
    2. **`lesson-sources`** — материалы юнита курса + внешние первоисточники (мост из
       материалов: MS-курс, каталоги примеров);
    3. **`own-docs`** — свои PDF/заметки/выгрузки (продолжение `/try`-сценариев).
  - `PROMPT_KIT` (общий для паков): готовые к копированию промпты — сравнение в таблицу ·
    вопросы с обязательными цитатами · аудио-обзор (кратко, с фокусом) · mind-map ·
    слайды. Каждый промпт требует от тетрадки **цитату с точкой в источнике** — это
    методологическое ядро, не украшение.
  - `VERIFY_CHECKLIST`: где тетрадка врёт — цитата не ведёт в источник · уверенный
    пересказ вместо цитаты · числа/проценты без точки в тексте · вопрос за пределами
    загруженных источников (отвечает «из головы») · выводы из одного источника поданы
    как консенсус. Мост к `00-kickstart/u4-sources` («Первоисточник или упаковка»).
  - `resolveNotebookPack(id, locale)` — как `resolveChain`.
- `components/notebook-pack.tsx` — рендер (копи-кнопки как в try-chains/learn-with-AI).
- `app/notebook/page.tsx` + `app/en/notebook/page.tsx` — открытая страница, без почты.
- Инструмент-агностика: страница называет Gemini Notebook (ex-NotebookLM) как референс
  и честно говорит: промпт-пак работает в любом чате, source-grounding сильнее в
  тетрадке. Никакого аффилиатства/обязательности подписки.

### Гварды (по канону курса)
- `lib/course/notebook-pack.test.ts`: обе локали у каждого Bi · `lintDehustle` на всей

## 3. M2 — модуль `09-ai-notebook` «Учиться с ИИ-тетрадкой»

### Решения
- **НЕ входит в `COURSE_CATALOG` воркера** — admission-гейт академии (`academy.ts`
  требует прогресс по КАЖДОМУ слагу каталога) не ужесточается задним числом. Модуль
  опциональный поверх ядра 00-08. Тест каталога (`course-catalog.test.ts` toEqual)
  остаётся как есть — это и есть гвард решения.
- Agent-agnostic: Gemini Notebook — референс-инструмент юнита 1 (бесплатный тир
  достаточен), но каждый юнит несёт «если тетрадки нет» — путь через обычный чат
  с приложенными файлами.
- Проза: RU основной + EN зеркало, пишется по канону speech/speedreading (факты
  проверяемые, ноль чужого копирайта, dehustle).

### Юниты (инверсия #102: артефакт → устройство → скепсис → форматы → практика)
1. **u1-first-notebook «Тетрадка за 15 минут»** — build-first: берёшь свой плейлист
   (или пак `youtube-playlist` с `/notebook`) → создаёшь тетрадку → задаёшь три вопроса
   из PROMPT_KIT → получаешь конспект с цитатами. Работающий артефакт до всякой теории.
2. **u2-how-it-works «Как это устроено»** — source-grounding: отвечает только по
   загруженному; цитата ведёт в точку транскрипта; чем отличается от чата «из головы»;
   почему транскрипт ≠ видео.
3. **u3-where-it-lies «Где оно врёт»** — VERIFY_CHECKLIST в действии: проверка цитат,
   пересказ вместо цитаты, ответы за пределами источников. Мост к 00/u4-sources.
4. **u4-formats «Форматы вывода»** — таблица/аудио/mind-map/слайды: когда какой формат
   работает, когда таблица честнее прозы, когда аудио — трата времени.
5. **u5-practice «Практика»** — по канону u5 других модулей: своя тетрадка под свою
   задачу (ниша из intake), чек-лист верификации как артефакт.

### Швы, которые обязан закрыть эпик (проверено по коду)

  их зелень = критерий.
- **Скин-паки:** framing нового модуля во всех 7 `lib/rpg/skins/*.json` (прецедент

- **World Map:** новая зона модуля (`lib/rpg/map-layout.ts`) + `transformations.ts`

- `lib/course-order.ts` (бот-дрип `/continue`) — добавить 09 в конец порядка.
- Ссылка u1 → `/notebook` (локале-верная, links-integrity проверит).

## 4. Вне скоупа
- Никакого backend/ручек воркера, никакого запуска LLM курсом (движок = handoff).
- Автоимпорт материалов юнитов в тетрадку (API тетрадки) — нет официального API; при
  появлении — отдельный intake.
- N3/N4 (личная тетрадка владельца в NAUTILUS через personal-полосу) — другой трек.
- Перевод модуля в COURSE_CATALOG (ужесточение админки) — только отдельным owner-решением.
