Дата: 2026-08-09 · Статус: approved-by-owner (design-gate пройден в сессии)

## Цель

Перезапустить коучинговую практику владельца как офлайн+цифровой контур:

- **Личный бренд ведёт** — mamaev.coach (mentor + blog + hub/events) остаётся витриной и воронкой.
- **Площадка и beachhead** — The Healing Society (wellness-коворк, East Nashville:
  8 почасовых приватных офисов, event-пространство, студия; аудитория — целители и
  терапевты холистических модальностей, по уровню зрелости почти все AI Curious;
  туры ср/сб 10:00 через Calendly).
- **Учебник** — Точка Сборки (ai.synergify.com), готовый двуязычный курс.

## Рамка (переплавка, НЕ калька)

Английский канон практики; финальные имена — owner-gate (authenticity sacred),
рабочие кандидаты:

| Источник (intake #109) | Наш канон | Примечание |

| PersonalOS | **Practice OS** | у целителей «practice» = и практика, и бизнес |

## Слайсы

Все четыре ведутся параллельно (гибрид A+B+C по решению владельца); ворота стоят
только перед S4.

### S1 — Эссе-манифест (blog, EN, kind:post)
Манифест рамки своим голосом: де-гуру, нить founder-story (учитель кундалини-йоги →
суверенные AI-инструменты), три уровня зрелости, Practice OS, rough-draft-first.
Фундамент копирайтинга для S2/S3. Проза — owner-approved verbatim перед шипом
(канон verbatim-owner-prose: черновик в плане → шип character-for-character).

### S2 — Intro-воркшоп «AI for healers» (hub/events)
Бесплатный taster в event-пространстве коворка. Лендинг по образцу
`hub/lib/events.ts` (сид `retreat-inner-evolution`): `EventConfig` + capture-форма,
свой `event`-тег в `event_leads`. Authenticity: даты прозой, без countdown/scarcity.
**Дата не публикуется**, пока владелец не сходил на тур и не оформил отношения
с площадкой — до тех пор лендинг может жить dark (фасад-паттерн, как AMA).

### S3 — Коучинг-оффер (mentor)
Страница оффера: диагностика клиента по трём уровням → построение его Practice OS
(память + база знаний + агенты + автоматизации практики), 1:1 в почасовом офисе
коворка. Обновляет mentor-персону, ссылается на S1-эссе. Форматы/цены — owner-gate.

### S4 — Платная когорта (⛔ ворота валидации)
Групповой интенсив «собери Practice OS» в event-пространстве, Точка Сборки как
учебник. **Не стартует, пока S2-воркшоп не показал спрос**: порог (N захватов или
N живых участников) фиксируется в тикете S4 при заведении и правится только владельцем.
Внутри: формат (недели/встречи), цена, учебный контур поверх курса, расписание.

## Архитектура / поверхности

Новых аппов НЕТ — только существующие движки mc_hub:
- blog: пост EN (`npm run new:post`), граф/manifest подхватят штатно
- hub: `EVENTS` config-driven лендинг + `capture-form` (worker/D1 уже принимает)
- mentor: контент-страница + правка mentor-persona SoT (`lib/mentor-persona.ts` — binding drift-guard уже стоит)
- Точка Сборки: НЕ трогаем (учебник as-is)

## Риски и границы

1. **Sole-prop sacred** — никаких nonprofit/tax-deductible фреймов.
2. **Authenticity** — вся проза owner-approved verbatim; регалии не выдумываем;
   рамку НЕ подаём как чужую методику и не копируем текст лендинга-источника.
3. **Язык** — контур EN-first; RU-поверхности этим эпиком не трогаем.
4. **Площадка** — членство/аренда не оформлены; публичные даты только после тура.
5. **Gotcha 6 доски** — fb.jsonl append-log: статусы читать по последней записи.
