# Академия-манифест: инбокс заметок владельца

Сюда падают сырые заметки под манифест и ребрендинг академии S.A.S.H.A
(«закрытая школа скрытых способностей», вход после Точки Сборки).

- **Формат:** один файл = одна заметка, `YYYY-MM-DD-<slug>.md`. Голосовые/чатовые
  сбросы владельца агент оформляет сюда verbatim (без редактуры смысла).
- **Приватность:** репо PUBLIC → всё в этой папке (кроме README) в git НЕ уходит
  (.gitignore корня). Заметки — сырьё, не публикация.
- **Потребитель:** `scripts/academy-manifesto-prompt.mjs` вплетает все заметки в
  промпт для агента владельца (sovereign prompt-emitter, ноль live-LLM).
  Запуск: `node scripts/academy-manifesto-prompt.mjs` из корня репо.
- Противоречия между заметками — побеждает более поздняя (по дате в имени).

## Сохранность
Папка — вложенный git-репозиторий с private remote **master5d/academy-notes**
(родительский public-репо её игнорирует). Каждая новая заметка сразу коммитится
и пушится туда — заметки переживают чистки, `git clean` и смерть диска.
